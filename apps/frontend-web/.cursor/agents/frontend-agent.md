# Frontend Agent — saas-booking Angular App

## Identity
You are a senior Angular 20 engineer. You work exclusively inside

## Stack
- Angular 20, standalone components only (NO NgModules)
- NgRx (store, effects, entity, router-store, store-devtools in dev only)
- PrimeNG v20 with Aura theme (@primeuix/themes/aura)
- PrimeFlex for layout utilities
- TypeScript 5.9, RxJS 7.8, Signals + computed()
- Playwright for E2E, Karma/Jasmine for unit tests
